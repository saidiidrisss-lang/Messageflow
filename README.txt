MessageFlow — volledige interactieve schooldemo

Open index.html in een browser. De app heeft:
- dashboard
- CSV-import via bestandskiezer
- contactenlijst
- berichteditor
- lokale verzend-simulatie
- statussen en voortgang
- logboek
- lokale opslag/hervatten

Let op: de demo verstuurt geen echte SMS.
Voor echte iPhone-PWA-installatie moet deze map via HTTPS worden gehost; daarna Safari -> Deel -> Zet op beginscherm.
